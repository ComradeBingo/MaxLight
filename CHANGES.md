# Изменения для функции "Спрашивать каждый раз при скачивании"

## Описание
Добавлена функция, которая позволяет пользователю выбирать путь для сохранения файла при каждом скачивании.

## Изменения в файлах

### 1. SettingsForm.cs
- Добавлен чекбокс "Спрашивать каждый раз при скачивании" в секции "Папка загрузок"
- Добавлен обработчик события `AskEveryTimeToggled`, который сохраняет настройку в `config.json`
- Добавлен чекбокс в список `this.Controls.Add()`

### 2. Form1.WebView2.cs
- Добавлен обработчик `OnDownloadStarting` для события `DownloadStarting`
- Проверяется настройка "Спрашивать каждый раз" из `ConfigManager.AskEveryTime()`
- Показывается диалоговое окно выбора пути для сохранения файла
- Используется рефлексия для доступа к свойствам `SuggestedSavePath` и `SaveAsPath` (для совместимости с .NET Framework 4.7)
- Если отмена - файл сохранится в папку по умолчанию

### 3. ConfigManager.cs
- Добавлен метод `SaveAskEveryTime(bool value)` для сохранения настройки
- Добавлен метод `AskEveryTime()` для загрузки настройки

## Как это работает

1. При скачивании файла проверяется настройка "Спрашивать каждый раз"
2. Если включена - показывается диалоговое окно выбора пути для сохранения
3. Пользователь может выбрать путь или отменить сохранение
4. Если отмена - файл сохранится в папку по умолчанию
5. Настройка сохраняется в `config.json`

## Совместимость
- Работает в .NET Framework 4.7
- Используется рефлексия для доступа к свойствам WebView2
- Совместимо с WebView2 Runtime

## Примечания
- Настройка сохраняется автоматически при изменении чекбокса
- При закрытии и перезапуске программы настройка сохраняется
